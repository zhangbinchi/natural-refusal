# Data Layout

The release does not include large datasets. The scripts expect local files with
the following schemas.

## Harmful Prompts

JSONL with one prompt per line:

```json
{"prompt": "harmful instruction text"}
```

Default path:

```text
data/beavertail_dataset/beavertail_train_harmful_diverse.jsonl
```

## Natural SFT Labels

Generated by `generate_sft_labels.py`:

```json
{"prompt": "harmful instruction text", "answer": "prompt-specific natural refusal"}
```

Default path:

```text
data/natural_label/generated_sft_labels.jsonl
```

## Benign Instruction Data

Alpaca-style JSON list:

```json
[
  {"instruction": "benign task", "input": "", "output": "helpful response"}
]
```

Default path:

```text
data/alpaca_dataset/alpaca_data_no_safety.json
```

## DPO Prompts and Candidate Pools

DPO prompt source:

```json
{"prompt": "harmful instruction text"}
```

Scored candidate pool produced by `generate_dpo_candidates.py`:

```json
{
  "prompt": "harmful instruction text",
  "candidates": ["response 1", "response 2"],
  "candidates_ppls": [2.3, 5.7],
  "candidates_rewards": [1.2, 0.4],
  "candidates_costs": [-0.8, 1.1]
}
```

DPO pairs produced by `select_dpo_pairs.py`:

```json
{"prompt": "harmful instruction text", "chosen": "safe natural target", "rejected": "unsafe or low-quality response"}
```
